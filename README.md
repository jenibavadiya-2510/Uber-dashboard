# 🚗 Uber Ride Analytics Dashboard | Power BI

## 📊 Project Overview

An interactive **Uber Ride Analytics Dashboard built using Microsoft Power BI** to analyze ride performance, revenue, customer behavior, vehicle types, booking status, and ride distance.

The dashboard transforms ride-booking data into meaningful visual insights using interactive KPIs, charts, tables, time-based analysis, and vehicle-level comparisons.

---

## 🎯 Purpose

The main purpose of this project is to **analyze Uber ride-booking performance and understand revenue and customer trends**.

This dashboard helps answer questions such as:

- How many rides were completed?
- How many bookings were lost?
- What is the total revenue generated?
- Which vehicle types generate the highest revenue?
- Which payment methods are most commonly used?
- How does revenue change monthly and quarterly?
- Which customers generate the highest revenue?
- How do customer segments differ by riding frequency?
- What is the average ride distance?
- How do ride performance and revenue vary across vehicle categories?
